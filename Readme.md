## 🚀 Live Demo
https://intercord.vercel.app

This project allows login access as a teacher or a student

A teacher can:

-  Create test
-  Publish test for all students
-  Assign marks
-  See leaderboard

A student can:

-  See all tests
-  Start a test
-  End a test
-  See leaderboard
